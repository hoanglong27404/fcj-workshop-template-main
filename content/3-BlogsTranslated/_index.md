### [Blog 1 - AWS WAF Integration with AWS Amplify Hosting](3.1-Blog1/)

**Author:** Sébastien Stormacq  
**Published:** March 26, 2025  
**Categories:** Announcements, AWS Amplify, AWS WAF, Featured, Front-End Web & Mobile, Launch, News, Security, Identity, & Compliance

This article introduces the AWS WAF (Web Application Firewall) integration feature with AWS Amplify Hosting, allowing you to directly attach a web application firewall to your Amplify application with just one click in the Amplify console or using Infrastructure as Code (IaC). Previously, deploying robust security for Amplify applications required complex CloudFront configurations. The new feature offers four protection types: Amplify-Recommended Protection, amplifyapp.com domain restriction, IP Protection, and Geographic Protection. Pricing follows standard AWS WAF model with additional $15/month when attached.

### [Blog 3 - From Virtual Machines to Kubernetes to Serverless: How Dacadoo Saved 78% on Cloud Costs](3.3-Blog3/)

**Authors:** Andreas Gehrig, Kevin Nash, Philippe Wanner  
**Published:** March 26, 2025  
**Categories:** Amazon API Gateway, Amazon DynamoDB, Amazon Route 53, Amazon Simple Storage Service (S3), Architecture, AWS Cloud Financial Management, AWS Lambda, AWS WAF, Migration, Serverless, Thought Leadership

Dacadoo's modernization journey through three architectural stages: from single VM to global Kubernetes clusters, and finally to fully serverless architecture. This transformation achieved 78% cost reduction, reduced maintenance time to under 1 hour/year, and reached 99.999% availability with geographic redundancy. The serverless solution uses DynamoDB Global Tables, API Gateway, Route 53 latency-based routing, Infrastructure as Code with Pulumi, and automated CI/CD with GitLab.
