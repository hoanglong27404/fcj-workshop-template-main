Các blog AWS đã dịch được tóm tắt và biên soạn dưới đây:

### [Blog 1 - Tích hợp AWS WAF với AWS Amplify Hosting](3.1-Blog1/)

**Tác giả:** Sébastien Stormacq  
**Xuất bản:** 26 tháng 3, 2025  
**Danh mục:** Thông báo, AWS Amplify, AWS WAF, Nổi bật, Front-End Web & Mobile, Ra mắt, Tin tức, Bảo mật, Danh tính & Tuân thủ

Bài viết này giới thiệu tính năng tích hợp AWS WAF (Web Application Firewall) với AWS Amplify Hosting, cho phép bạn gắn trực tiếp tường lửa ứng dụng web vào ứng dụng Amplify chỉ bằng một cú nhấp chuột trong bảng điều khiển Amplify hoặc sử dụng Infrastructure as Code (IaC). Trước đây, việc triển khai bảo mật mạnh mẽ cho các ứng dụng Amplify yêu cầu cấu hình CloudFront phức tạp. Tính năng mới cung cấp bốn loại bảo vệ: Bảo vệ được Amplify khuyến nghị, hạn chế domain amplifyapp.com, Bảo vệ IP và Bảo vệ Địa lý. Giá cả theo mô hình AWS WAF chuẩn với phí bổ sung $15/tháng khi gắn kèm.

### [Blog 2 - Từ Người mới bắt đầu với Cloud đến Nhà phát triển Game đoạt giải: Hành trình với AWS Cloud Institute](3.2-Blog2/)

**Tác giả:** Carlie Marvel  
**Xuất bản:** 1 tháng 4, 2025  
**Danh mục:** Amazon Bedrock, Amazon CloudFront, Amazon DynamoDB, Amazon Q Developer, Amazon Route 53, Amazon Simple Storage Service (S3), AWS Lambda, Đào tạo và Chứng chỉ AWS

Câu chuyện về sự chuyển đổi của JC Boissy từ một chuyên gia quản lý dự án CNTT không có kinh nghiệm cloud thành nhà phát triển game đoạt giải thông qua AWS Cloud Institute. Game CloudJack-21 kết hợp cơ chế blackjack với giáo dục dịch vụ AWS, sử dụng các công cụ AI như Amazon Q Developer để tối ưu quá trình phát triển. Hành trình bao gồm 12 khóa học, 150+ bài thực hành, kiến trúc serverless với AWS Lambda, DynamoDB, S3, CloudFront, Route 53, và các chứng chỉ bao gồm Cloud Practitioner, AI Practitioner và Solutions Architect Associate.

### [Blog 3 - Từ Máy ảo đến Kubernetes đến Serverless: Cách Dacadoo tiết kiệm 78% chi phí Cloud](3.3-Blog3/)

**Tác giả:** Andreas Gehrig, Kevin Nash, Philippe Wanner  
**Xuất bản:** 26 tháng 3, 2025  
**Danh mục:** Amazon API Gateway, Amazon DynamoDB, Amazon Route 53, Amazon Simple Storage Service (S3), Kiến trúc, Quản lý Tài chính AWS Cloud, AWS Lambda, AWS WAF, Migration, Serverless, Tư duy Lãnh đạo

Hành trình hiện đại hóa của Dacadoo qua ba giai đoạn kiến trúc: từ VM đơn lẻ đến các cụm Kubernetes toàn cầu, và cuối cùng là kiến trúc serverless hoàn toàn. Sự chuyển đổi này đạt được giảm 78% chi phí, giảm thời gian bảo trì xuống dưới 1 giờ/năm, và đạt 99.999% độ khả dụng với dự phòng địa lý. Giải pháp serverless sử dụng DynamoDB Global Tables, API Gateway, định tuyến dựa trên độ trễ Route 53, Infrastructure as Code với Pulumi và CI/CD tự động với GitLab.
