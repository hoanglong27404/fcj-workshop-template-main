##  Mục tiêu tuần 1

- **Khởi tạo và bảo vệ tài khoản AWS đầu tiên**
  - Tạo tài khoản AWS mới, bật MFA cho Root user  
  - Tạo nhóm/quyền Administrator, tạo tài khoản quản trị riêng  
  - Hỗ trợ xác thực tài khoản khi đăng nhập  
  - Làm quen và cấu hình AWS Management Console  

- **Quản lý chi phí với AWS Budgets**
  - Tạo Cost Budget, Usage Budget, Reservation Budget, Savings Plans Budget  
  - Thiết lập cảnh báo và quy trình dọn dẹp tài nguyên  

- **Tổng quan AWS Support**
  - Giới thiệu về các gói hỗ trợ và phạm vi dịch vụ AWS  

- **Quản trị truy cập với IAM**
  - Tạo Users và Groups  
  - Gắn Policies, tạo Roles  
  - Thực hành Switch Role  
  - Áp dụng nguyên tắc phân quyền tối thiểu  

- **Kiến thức mạng với VPC**
  - Giới thiệu về VPC, phân biệt Security Groups và Network ACL  
  - Chuẩn bị môi trường mạng triển khai EC2  
  - Dọn dẹp tài nguyên sau khi thực hành

### Những gì đã hoàn thành

- Tạo tài khoản AWS với $100 tín dụng miễn phí và bật bảo mật MFA  
- Tạo IAM User riêng để tránh sử dụng Root Account  
- Thiết lập ngân sách hàng tháng và cảnh báo chi phí  
- Hiểu rõ cơ chế phân quyền IAM và thực hành Switch Role  
- Nắm vững kiến trúc mạng VPC và bảo mật bằng Security Group  
- Triển khai thành công EC2 đầu tiên và kết nối SSH  
- Phân biệt rõ giữa Security Group và Network ACL  
- Hoàn tất dọn dẹp tài nguyên sau khi thực hành
