## Week 1 Objectives

- **Initialize and secure AWS account**
  - Create new AWS account, enable MFA for Root user
  - Create Admin group/role, assign admin privileges
  - Practice login with IAM user
  - Explore and configure AWS Management Console

- **Cost management with AWS Budgets**
  - Create Cost Budget, Usage Budget, Reservation Budget, Savings Plans Budget  
  - Configure alerts and cleanup process

- **Understand AWS Support**
  - Overview of AWS Support plans and services

- **Identity and Access Management (IAM)**
  - Create Users and Groups
  - Attach policies and create Roles
  - Practice Switch Role
  - Apply least privilege principle

- **Networking with VPC**
  - Introduction to VPC concepts  
  - Compare Security Groups vs Network ACLs  
  - Prepare network environment for EC2  
  - Resource cleanup after lab
