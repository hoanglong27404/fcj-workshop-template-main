### Week 3 Objectives

This week was dedicated to mastering core AWS services, from compute and databases to automation. The primary goals were:
-   **In-depth EC2 Exploration**: Learn to deploy and manage Windows and Linux virtual machines, build custom Amazon Machine Images (AMIs), handle Elastic Block Store (EBS) volumes, and implement cost governance policies.
-   **Security & Development Environments**: Gain proficiency in using IAM Roles for secure permissions and familiarize with the AWS Cloud9 cloud-based integrated development environment.
-   **Amazon S3 Storage Solutions**: Deploy a static website on S3, configure multi-region replication for data redundancy, and manage object versioning.
-   **Database Management**: Understand how to create and operate relational databases with Amazon RDS and explore cost optimization for smaller applications using Amazon Lightsail.
-   **Automation & Monitoring**: Establish systems for automatic resource scaling with EC2 Autoscaling, monitor system performance with Amazon CloudWatch, and configure hybrid DNS with Route 53.
