In this section, I share my journey of the first 5 weeks** when participating in the **AWS FCJ Internship** program – where I was able to access, learn and practice knowledge about **Cloud Computing\*\* from basic to advanced.

The program not only helped me master the basic services of AWS but also practice system thinking, operational ability, and deploy practical solutions – important skills for the future position of **Cloud Engineer** or **Solution Architect**.

---

## First 5-week learning program

### **Week 1: AWS Fundamentals – Basic foundation**

- Set up and secure personal AWS account.
- Manage costs with the **AWS Budgets** tool.
- Get familiar with **IAM** (Identity and Access Management) and authorization.
- Create your first virtual server using **Amazon EC2** and learn about **VPC** (Virtual Private Cloud) architecture.

---

### **Week 2: Advanced Networking**

- Set up a **Hybrid DNS** system using **Route 53 Resolver**.

- Configure **VPC Peering** and **AWS Transit Gateway** to connect networks between regions.

- Start sketching ideas and plans for the **final project**.

---

### **Week 3: Comprehensive AWS Services**

- Deep dive into **EC2** (Windows/Linux), create **Custom AMI** and manage **EBS** drives.

- Practice with **IAM Role**, **AWS Cloud9**, and **Amazon S3** to host static websites.

- Work with **RDS**, **Lightsail**, integrate **Auto Scaling** and monitor the system with **CloudWatch**.

---

### **Week 4: System Optimization – Optimize the system**

- **Operational Excellence:** Automate, monitor and deploy infrastructure as code (**Infrastructure as Code**).
- **Security:** Use **SSO**, limit **IAM Boundaries**, configure **WAF**, and manage encryption keys with **KMS**.
- **Reliability:** Backup and restore data with **AWS Backup**, set up multi-region connectivity via **VPC Peering** and **Transit Gateway**.
- **Performance:** Optimize with **Docker**, **ECS**, **CodePipeline**, **Data Lake**, and **DynamoDB**.

- **Cost Optimization:** Apply **Savings Plans**, adjust configuration appropriately and analyze overall costs.

---

### **Week 5: Project Development & Local Environment Setup**

- Translate and edit assigned **AWS technical blogs**.

- Review and consolidate key knowledge from week 4.
- Set up a local development environment for the upcoming project.

- Install **DynamoDB Local** via **Docker** for offline testing.
- Get familiar with **AWS CDK** and organize the infrastructure project structure.

---
